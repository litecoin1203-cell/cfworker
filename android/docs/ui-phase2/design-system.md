# سیستم طراحی Cloud Gold (فاز ۲)

منبع: `app-web/tokens.css` (توکن‌ها و اجزا)، `app-web/ui.js` (اجزای مشترک)، `app-web/i18n.js` (همه‌ی رشته‌ها).

## ۱. توکن‌ها (سه لایه)

صفحه‌ها فقط از لایه‌ی ۲ و ۳ استفاده می‌کنند؛ رنگ خام در کد صفحه نیست.

| لایه | نمونه | کاربرد |
|---|---|---|
| ۱. Primitive | `--p-walnut-950`، `--p-bullion-400`، `--p-verdigris-300`، `--p-cinnabar-300`، `--p-amber-300`، `--p-platinum-50` | فقط برای تعریف لایه‌ی ۲ |
| ۲. Semantic (برای `data-theme="dark"` و `"light"`) | `--c-bg`، `--c-surface` / `-2` / `-3`، `--c-text` / `-2` / `-3`، `--c-line`، `--c-accent`، `--c-on-accent`، `--c-focus`، `--c-ok` / `--c-busy` / `--c-warn` / `--c-bad` و `*-bg` هر کدام | رنگ‌ها با نقش |
| ۳. Component | `--btn-h` (۵۲px+)، `--row-min` (۵۶px+)، `--touch` (حداقل ۴۸px)، `--tab-h`، `--meter-h`، `--meter-track` | اندازه و رنگ اجزا |

- **فاصله:** شبکه‌ی ۴px به rem: `--s-1`=۴ تا `--s-12`=۴۸؛ حاشیه‌ی صفحه `--gutter`.
- **شعاع (سلسله‌مراتب):** چیپ ۱۰، ردیف ۱۴، کارت ۲۲، شیت ۲۸، دکمه‌ی قرصی `--r-pill`.
- **حرکت:** `--m-quick` ۱۲۰ms، `--m-standard` ۲۴۰ms، `--m-emph` ۴۲۰ms، منحنی `--ease`. اگر کاربر «کاهش حرکت» را روشن کرده باشد، انیمیشن‌ها حذف می‌شوند.
- **حالت‌ها (Material 3):** فشرده `--st-pressed` ۰٫۱۲، غیرفعال `--st-disabled` ۰٫۳۸، فوکوس حلقه‌ی `--c-focus`.
- **تایپوگرافی:** Vazirmatn برای متن و Markazi برای عددهای بزرگ. کلاس‌های `.t-h1`، `.t-h2`، `.t-body`، `.t-small`. همه‌ی اندازه‌ها rem هستند و `--fs` (از `fontScale` اندروید) آن‌ها را بزرگ می‌کند.
- **کنتراست (اندازه‌گیری خودکار):** متن روی پس‌زمینه ۱۶ (تیره) و ۱۴٫۶ (روشن). ضعیف‌ترین جفت، `text-3` روی surface در تم تیره، ۴٫۵۱ است. همه‌ی جفت‌های وضعیت ≥ ۴٫۷ هستند؛ همه ≥ AA ۴٫۵.

## ۲. اجزای مشترک (`CG.ui`)

| جزء | خروجی | قاعده |
|---|---|---|
| `statusChip(phase)` | `.status.ok/busy/warn/bad/idle` | همیشه **آیکن + کلمه + رنگ**؛ هیچ وضعیتی فقط با رنگ گفته نمی‌شود |
| `notice(kind, title, sub, action)` | `.notice` | `role=alert` برای warn/bad و `role=status` برای بقیه |
| `appBar(title, {back, trailing})` | `.appbar` | دکمه‌ی برگشت در RTL برعکس می‌شود (`.flip-rtl`) |
| `tabs(active)` | `.tabs` | چهار تب اتصال، سرورها، اشتراک و تنظیمات؛ `aria-current="page"` |
| `switchRow` | `.row[role=switch]` | `aria-checked` فقط بعد از جواب واقعی سیستم عوض می‌شود |
| `linkRow` | `.row` + شِورون | |
| `fsheet(html)` | شیت پایین صفحه | `role=dialog`، فوکوس روی عنوان، با بستن به دکمه‌ی قبلی برمی‌گردد |
| `announce(text)` | ناحیه‌ی `aria-live` | برای خبر دادن نتیجه به TalkBack |
| `errText(err)` | متن خطای قابل‌فهم | فقط از روی کد خطا؛ جزئیات فنی سرور نشان داده نمی‌شود |

سایر اجزا: `.btn` (primary / quiet / outline / danger)، `.chip` (`aria-pressed` یا `aria-checked`)، `.meter`، `.ring` (حلقه‌ی مصرف)، `.kv` (برچسب و مقدار)، `.card`، `.srow` (ردیف سرور)، `.plan` (کارت پلن، `role=radio`).

## ۳. قواعد وضعیت

**اتصال** (`CG.phase()`):

| phase | رنگ | آیکن | کلمه |
|---|---|---|---|
| connected | ok | سپر تیک‌دار | وصل |
| connecting / disconnecting | busy | چرخان | در حال اتصال / قطع |
| disconnected | idle | سپر خاموش | قطع |
| error | bad | هشدار | خطا |
| blocked | bad | توقف | متوقف (دلیل از `stopReason()`) |

**قواعد دیگر:**
- **هشدار مصرف:** فقط از `subscription.used_percent` سرور. ۸۰ = warn، ۹۵ = bad، ۱۰۰ = bad همراه با دلیل توقف و دکمه‌ی تمدید. `days_left ≤ 3` = warn.
- **Kill Switch / Always-On:** «فعال» فقط وقتی نشان داده می‌شود که اندروید `isLockdownEnabled` / `isAlwaysOn` را true گزارش کند. در غیر این صورت «غیرفعال» یا «نامشخص» با دلیل نشان داده می‌شود.
- **اجازه‌های سیستم** (اتصال خودکار، اعلان): کلید فقط وقتی روشن می‌شود که اندروید اجازه داده باشد. اگر رد کند، کلید برمی‌گردد و یک پیام دلیل را می‌گوید.
- **حریم خصوصی:** به صفحه هیچ آدرس سرور، پورت، آدرس پنل، توکن یا IP خروجی نمی‌رسد. سرورها با کلید هش‌شده‌ی `k` شناخته می‌شوند.
- **RTL/LTR:** جهت سند برای هر صفحه از زبان انتخاب‌شده تنظیم می‌شود. عددها در RTL راست‌چین و با ارقام فارسی نوشته می‌شوند. ساعت مدت اتصال همیشه LTR است.
