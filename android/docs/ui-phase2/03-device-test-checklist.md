# چک‌لیست تست دستی روی گوشی

**پیش‌نیاز:** APK همین شاخه از workflow «Build Cloud Gold APK» و یک حساب قدیمی که قبلاً وارد شده است. اپ را روی نسخه‌ی قبلی نصب کنید (آپدیت، نه نصب تازه).

## حساب کاربر قدیمی
- [ ] بعد از آپدیت، بدون ورود دوباره، مستقیم خانه باز می‌شود.
- [ ] UUID و لینک سابسکریپشن عوض نمی‌شود. مقایسه با پنل: همان کاربر و همان مصرف.

## اتصال و قطع
- [ ] لمس دکمه: چیپ از «در حال اتصال» به «وصل» می‌رود و آیکن و کلمه با هم عوض می‌شوند.
- [ ] مدت اتصال هر ثانیه بالا می‌رود. مصرف جلسه بعد از چند صفحه وب بیشتر می‌شود.
- [ ] لمس دوباره قطع می‌کند، و ردیف‌ها کم‌رنگ می‌شوند و «—» نشان می‌دهند.
- [ ] رد کردن اجازه‌ی VPN، پیام قابل‌فهم نشان می‌دهد و چیپ «وصل» نمی‌شود.

## تغییر سرور
- [ ] تب سرورها: جست‌وجوی «آلمان» یا «germ» نتیجه می‌دهد و با پاک کردن، لیست کامل برمی‌گردد.
- [ ] «تست تأخیر همه»: عددها یکی‌یکی می‌آیند، لیست وسط تست جابه‌جا نمی‌شود و بعد از پایان، اگر مرتب‌سازی تأخیر روشن باشد، مرتب می‌شود.
- [ ] ستاره: سرور در «منتخب‌ها» می‌ماند، حتی بعد از بستن اپ.
- [ ] انتخاب یک سرور وقتی وصل هستید: اتصال روی سرور جدید ری‌استارت می‌شود و خانه سرور جدید را نشان می‌دهد.
- [ ] هیچ‌جا (صفحه، اعلان، TalkBack) آدرس یا نام پنل، دامنه‌ی سرور یا IP دیده یا شنیده نمی‌شود.

## قطع شبکه وسط اتصال
- [ ] حالت هواپیما در حین اتصال: پیام «اینترنت گوشی قطع است…» ظاهر می‌شود. با برگشت شبکه، اتصال هوشمند سرور بعدی را امتحان می‌کند.
- [ ] Wi-Fi به دیتا: وضعیت درست می‌ماند و اپ هنگ نمی‌کند.

## onRevoke (VPN دیگری روشن شود)
- [ ] در حین اتصال، یک VPN دیگر را وصل کنید و به اپ برگردید. باید چیپ «قطع» و اعلان «اتصال قطع شد» نشان داده شود. نباید «وصل» دروغین ببینید.

## Kill Switch / Always-On
- [ ] قطع: هر دو «نامشخص؛ فقط وقتی وصل هستی…».
- [ ] وصل، بدون تنظیم سیستم: «غیرفعال».
- [ ] تنظیمات ← راهنما ← «باز کردن تنظیمات VPN اندروید» ← هر دو گزینه را روشن کنید ← برگردید: پیام «اندروید تأیید کرد…» و هر دو «فعال».
- [ ] اندروید ۹ یا پایین‌تر: «نامشخص؛ اندروید این گوشی وضعیت را به اپ نمی‌گوید».

## اتصال خودکار و اعلان‌ها
- [ ] روشن کردن اتصال خودکار بدون اجازه‌ی VPN: دیالوگ اندروید باز می‌شود. اگر رد کنید، کلید خاموش برمی‌گردد و پیام دلیل نشان داده می‌شود.
- [ ] ری‌استارت گوشی با اتصال خودکار روشن: VPN خودش وصل می‌شود.
- [ ] اندروید ۱۳ به بالا: رد اجازه‌ی اعلان، کلید را خاموش نگه می‌دارد و دکمه‌ی «باز کردن تنظیمات اعلان» ظاهر می‌شود.

## مصرف و تمدید
- [ ] عددهای تب اشتراک دقیقاً با `/me` (یا پنل) برابرند: مصرف، باقیمانده، کل، روز مانده و تاریخ.
- [ ] با کاربری در ۸۰٪، ۹۵٪ و ۱۰۰٪: هشدار درست نشان داده می‌شود. در ۱۰۰٪ یا بعد از انقضا، دلیل همراه با «تمدید اشتراک» نمایش داده می‌شود.
- [ ] خرید یا تمدید با کیف پول: صفحه‌ی موفقیت وضعیت جدید سرور را نشان می‌دهد. در پنل حساب جدیدی ساخته نشده است.

## ظاهر و دسترس‌پذیری
- [ ] تم تیره، روشن و «مثل گوشی» (با تغییر تم سیستم): همه‌ی صفحه‌ها خوانا هستند و نوار وضعیت هم‌رنگ است.
- [ ] اندازه‌ی فونت سیستم «بزرگ‌ترین»: هیچ متنی بریده یا روی هم نیست و تب‌بار جا می‌شود.
- [ ] چرخش صفحه: Activity روی portrait قفل است (رفتار قبلی). چیدمان افقی در پیش‌نمایش تست شده است، اگر بعداً قفل برداشته شود.
- [ ] TalkBack: دکمه‌ی اتصال «اتصال، قطع» خوانده می‌شود. تغییر وضعیت اعلام می‌شود. ستاره «افزودن … به منتخب‌ها» خوانده می‌شود. کلیدها وضعیت روشن/خاموش دارند. حلقه‌ی مصرف «مصرف: … از …» خوانده می‌شود.
- [ ] زبان English: همه‌ی صفحه‌های جدید LTR هستند و پیکان‌ها و شورون‌ها جهت درست دارند.
