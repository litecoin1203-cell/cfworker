# Cloud Gold VPN — نسخه‌ی کامل روی Cloudflare (رایگان، بدون سرور)

کل فروشگاه روی **Cloudflare** اجرا می‌شود و **هیچ VPS‌ای لازم ندارد**. فقط هزینه‌ی یک دامنه در سال.

- **سرور (Cloudflare Worker)** = API فروشگاه؛ **دیتابیس (Cloudflare D1)** = حساب‌ها، سفارش‌ها، کیف پول.
- **ربات تلگرام روی همان Worker** = مدیریت کامل فروش از داخل تلگرام (تأیید/رد رسید، آمار، تغییر تنظیمات).
- **اپ اندروید** روی هسته‌ی کامل v2rayNG 2.2.6 که با API نمایندگی تو یوزر می‌سازد.
- ثبت‌نام، خرید پلن، کارت‌به‌کارت، کیف پول، تست رایگان، دعوت دوستان — همه داخل اپ.

```
cfworker/
├── worker/     سرور Cloudflare (کد + دیتابیس + ربات تلگرام) — ۵۳ تست خودکار دارد
├── app-web/    ظاهر اپ
├── android/    سورس v2rayNG 2.2.6 + پل Cloud Gold
└── .github/workflows/
      ├── deploy-worker.yml   بالا بردن سرور روی Cloudflare
      ├── make-key.yml        ساخت کلید امضا (یک بار)
      └── android.yml         ساخت APK
```

> نسخه‌ی ساده‌تر (فقط اپ، بدون سرور و بدون فروشگاه) هم قبلاً برایت ساخته شد. این نسخه فروشگاه کامل دارد ولی راه‌اندازی‌اش چند قدم بیشتر است.

---

## چه چیزهایی لازم داری
1. یک حساب **Cloudflare** (رایگان) — `dash.cloudflare.com`
2. یک **دامنه** روی Cloudflare (پیشنهاد جدی؛ در ایران بازتر از آدرس رایگان `workers.dev` است)
3. یک حساب **GitHub** (رایگان)
4. یک **ربات تلگرام** (رایگان، از BotFather)
5. دسترسی **API نمایندگی** پنل PasarGuard (همین که الان داری)

---

## قدم ۱: ربات تلگرام
1. در تلگرام به **@BotFather** پیام بده: `/newbot` → یک اسم و یوزرنیم بده.
2. **توکن** رباتی که می‌دهد را یادداشت کن (`TELEGRAM_BOT_TOKEN`).
3. یک **رمز وبهوک** دلخواه برای خودت بساز (`TELEGRAM_WEBHOOK_SECRET`): حداقل ۸ کاراکتر و فقط حروف انگلیسی، عدد، `_` و `-`، مثل `cg_x7Rk2pQ9`. این را جایی یادداشت کن. **اجباری است:** بدون آن ربات ادمین هیچ پیامی را قبول نمی‌کند.
4. چت آیدی‌ات را بعداً (قدم ۵) می‌گیری.

## قدم ۲: دامنه روی Cloudflare
1. در Cloudflare روی **Add a site** بزن و دامنه‌ات را اضافه کن.
2. Cloudflare دو تا **Nameserver** می‌دهد؛ آن‌ها را در پنل جایی که دامنه را خریدی ثبت کن.
3. چند دقیقه تا چند ساعت طول می‌کشد تا فعال شود.
4. آدرس سرورت این خواهد بود: `https://api.yourdomain.com` (به‌جای yourdomain دامنه‌ی خودت).

## قدم ۳: توکن API کلودفلر
1. در Cloudflare برو به **My Profile → API Tokens → Create Token**.
2. قالب **Edit Cloudflare Workers** را انتخاب کن و بساز. این `CLOUDFLARE_API_TOKEN` است.
3. در صفحه‌ی اصلی داشبورد، سمت راست، **Account ID** را کپی کن (`CLOUDFLARE_ACCOUNT_ID`).

## قدم ۴: پروژه روی GitHub
1. **GitHub Desktop** را از `desktop.github.com` نصب کن و وارد شو.
2. فایل zip را Extract کن (پوشه‌ی `cfworker`).
3. در GitHub Desktop: **File → Add local repository** → پوشه‌ی `cfworker` → **create a repository** → Commit → **Publish repository** (تیک **Keep this code private** روشن).

## قدم ۵: ثبت تنظیمات در GitHub
در ریپو برو به **Settings → Secrets and variables → Actions** و در تب **Secrets** این‌ها را بساز (هر کدام با New repository secret):

| Secret | مقدار |
|---|---|
| `CLOUDFLARE_API_TOKEN` | توکن قدم ۳ |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID قدم ۳ |
| `SECRET_KEY` | یک رشته‌ی تصادفی بلند. (مثلاً در گوگل «random password 48» بزن) |
| `PUBLIC_BASE_URL` | `https://api.yourdomain.com` |
| `PASARGUARD_URL` | آدرس پنل، مثل `https://panel.example.com:8000` |
| `PASARGUARD_USERNAME` | یوزر نمایندگی |
| `PASARGUARD_PASSWORD` | رمز نمایندگی |
| `PASARGUARD_USERNAME_PREFIX` | مثلاً `cg` |
| `TELEGRAM_BOT_TOKEN` | توکن ربات قدم ۱ |
| `TELEGRAM_WEBHOOK_SECRET` | رمز وبهوک قدم ۱ |

اختیاری (اگر API key داری به‌جای یوزر/رمز نمایندگی): `PASARGUARD_API_KEY`.
اختیاری (کریپتو): `NOWPAYMENTS_API_KEY`، `NOWPAYMENTS_IPN_SECRET`.

> `TELEGRAM_CHAT_ID` را هنوز نگذار؛ در قدم ۷ می‌گیریم.

## قدم ۶: بالا بردن سرور
1. در ریپو برو به تب **Actions** (اگر غیرفعال بود، فعالش کن).
2. از چپ **Deploy Cloud Gold server** را انتخاب کن و **Run workflow** را بزن.
3. حدود ۲ تا ۳ دقیقه صبر کن تا تیک سبز بخورد. این کار دیتابیس را می‌سازد، رمزها را روی Cloudflare می‌گذارد، سرور را بالا می‌برد و ربات تلگرام را وصل می‌کند.
4. **اتصال دامنه به سرور:** در Cloudflare برو به **Workers & Pages → cloudgold → Settings → Domains & Routes → Add → Custom domain** و `api.yourdomain.com` را وارد کن. چند دقیقه بعد `https://api.yourdomain.com/health` باید `{"ok":true}` بدهد.
   - اگر فعلاً دامنه نداری، در همان صفحه آدرس `workers.dev` را روشن کن و آن آدرس را به‌جای `api.yourdomain.com` همه‌جا استفاده کن (ولی ممکن است در ایران باز نشود).

## قدم ۷: وصل کردن ربات و تنظیم فروشگاه
1. ربات تلگرامت را باز کن و `/id` بفرست. عددی که می‌دهد **چت آیدی** توست.
2. در GitHub یک Secret جدید بساز: `TELEGRAM_CHAT_ID` با همان عدد. بعد یک بار دیگر **Deploy Cloud Gold server** را اجرا کن تا اعمال شود.
3. حالا در ربات این دستورها را بفرست تا فروشگاه را تنظیم کنی:
   ```
   /set card_number 6037xxxxxxxxxxxx
   /set card_holder نام صاحب کارت
   /set card_bank ملی
   /set support_url https://t.me/your_id
   /set usdt_rate_toman 70000
   /set pg_group_ids 1
   ```
   - `pg_group_ids`: شماره‌ی گروه فروش در PasarGuard (اگر چند تا: `1,3`).
   - `/help` همه‌ی دستورها را نشان می‌دهد؛ `/plans` پلن‌ها، `/stats` آمار فروش.
4. **تأیید رسید:** وقتی مشتری کارت‌به‌کارت کند و رسید بفرستد، عکس رسید با دو دکمه‌ی **✅ Approve** و **❌ Reject** برایت در تلگرام می‌آید. با یک لمس تأیید یا رد کن.

## قدم ۸: ساخت APK
1. در تب **Actions**، **Create signing key (run once)** را اجرا کن، یک رمز بده (یادداشت کن)، فایل `signing-key` را دانلود کن.
2. در **Settings → Secrets** این چهارتا را بساز: `APP_KEYSTORE_BASE64` (محتوای فایل txt داخل signing-key)، `APP_KEYSTORE_PASSWORD`، `APP_KEY_PASSWORD` (همان رمز)، `APP_KEYSTORE_ALIAS` = `cloudgold`.
3. در **Settings → Variables** یک Variable بساز: `CG_API_BASE` با مقدار آدرس سرورت. می‌توانی چند آدرس را با کاما بگذاری تا اگر یکی فیلتر شد اپ سراغ بعدی برود:
   ```
   https://api.yourdomain.com
   ```
4. در **Actions** → **Build Cloud Gold APK** → Run workflow. حدود ۲۰ دقیقه بعد فایل `CloudGold-1.0.0` را دانلود کن (`...universal.apk` روی همه‌ی گوشی‌ها نصب می‌شود).

## قدم ۹: تست
1. APK را روی گوشی نصب کن.
2. ثبت‌نام کن (ایمیل + رمز، بدون کد تأیید).
3. **Start Free Trial** را بزن یا در ربات `/grant ایمیل شماره‌پلن` بفرست.
4. دکمه‌ی پاور را بزن و درخواست VPN را قبول کن → باید **Connected** شود.
5. یک خرید کارت‌به‌کارت آزمایشی کن و از تلگرام تأییدش کن.

## نسخه ۱.۱ — چه چیزهایی اضافه شد
- **ساخت اکانت روی پنل محکم‌تر شد:** آدرس پنل به هر شکلی وارد شود (مثلاً `.../hub/#/login`) درست خوانده می‌شود. برای نمایندگی‌هایی که اجازه‌ی دیدن همه‌ی گروه‌ها را ندارند، لیست ساده‌ی گروه‌ها خوانده می‌شود.
- **دستور `/panel` در ربات:** ورود به پنل، گروه‌ها، ساخت یک اکانت آزمایشی و لینک ساب را تست می‌کند و دقیق می‌گوید مشکل کجاست.
- **خطای دقیق پنل در تلگرام** + دکمه‌ی **🔁 دوباره بساز** برای سفارش‌هایی که فعال نشدند.
- **حجم و زمان باقی‌مانده، زنده از پنل** در صفحه‌ی اصلی و «اشتراک من»، و یادآوری تمدید وقتی کمتر از ۳ روز یا ۱۰٪ حجم مانده.
- **اتصال هوشمند:** سریع‌ترین سرور خودکار انتخاب می‌شود؛ اگر سرور جواب ندهد، خودکار سرور بعدی.
- **سایت‌های ایرانی بدون VPN** (قابل خاموش کردن در «تنظیمات اتصال»).
- **اگر آدرس پنل روی اینترنت کاربر فیلتر باشد**، لیست سرورها از طریق سرور Cloudflare گرفته می‌شود.
- **اپ کاملاً فارسی** (راست‌به‌چپ، تاریخ شمسی، فونت وزیرمتن).
- **کد تخفیف:** `/coupon YALDA 20 100 7` (۲۰٪، ۱۰۰ بار، ۷ روز). `/coupons` و `/delcoupon`.
- **کیف پول + پرداخت مابقی:** اگر موجودی کم باشد، کاربر فقط مابقی را کارت‌به‌کارت می‌کند و بعد از تأیید، پلن خودکار فعال می‌شود.
- **ویرایش پلن‌ها از ربات:** `/plans`، `/plan 1 price 199000`، `/newplan`.
- **پشتیبان خودکار:** هر شب ساعت ۰۰:۰۰ فایل پشتیبان و گزارش فروش در تلگرام. دستی: `/backup`.
- `/set trial_data_gb 2` = حجم تست رایگان (۰ = مثل پلن).

## نسخه ۱.۲ — درگاه ارز دیجیتال Cloud Gold Pay
پول مستقیم به **ولت خودت** واریز می‌شود؛ واسط و کارمزد درگاه ندارد. تتر (USDT) عمداً حذف شده است و فقط ارزهایی هستند که **کارمزد انتقال خیلی پایینی** دارند (BTC و ETH به خاطر کارمزد بالا حذف شدند).

ارزها: **XLM، XRP، TRX، SOL، TON، LTC، DOGE، BCH، BNB (BEP20)، POL، ALGO**

**راه‌اندازی در ربات:**
```
/set wallet_xlm آدرس_استلار
/set wallet_xlm_memo 84021733
/set wallet_trx آدرس_ترون
/wallets
```
- **Memo / Tag:** برای XLM، XRP و TON اگر آدرس مال **صرافی** است، حتماً Memo را هم بگذار (`wallet_xlm_memo`، `wallet_xrp_memo` که فقط عدد است، `wallet_ton_memo`). اپ آن را با هشدار قرمز به کاربر نشان می‌دهد. اگر ولت شخصی است، Memo لازم نیست.
- هر ارزی که آدرس داشته باشد، در اپ نشان داده می‌شود. آدرس اشتباه را ربات قبول نمی‌کند.
- **قیمت‌ها کاملاً خودکار است:** قیمت دلار هر ۵ دقیقه از ۵ صرافی ایرانی (نوبیتکس، والکس، بیت‌پین، رمزینکس، تبدیل) گرفته می‌شود و **میانه** استفاده می‌شود؛ قیمتی که خیلی با بقیه فرق دارد کنار گذاشته می‌شود. قیمت جهانی ارزها هم خودکار است. `/rate` جواب هر صرافی را نشان می‌دهد.
- اگر همه‌ی صرافی‌ها قطع بودند، آخرین قیمت ذخیره‌شده (تا ۲۴ ساعت) و بعد `usd_rate_toman` دستی استفاده می‌شود (فقط برای مواقع اضطراری).
- هر سفارش یک **مبلغ یکتا** می‌گیرد (مثلاً 4.72502 XLM) تا واریز دقیقاً با سفارش تطبیق داده شود. قیمت ۳۰ دقیقه قفل است (`/set coin_minutes 30`).
- کاربر «پرداخت کردم» را می‌زند (با هش تراکنش، اختیاری). در تلگرام برایت پیام می‌آید با مبلغ، شبکه، Memo، دکمه‌ی **دیدن تراکنش** و **ورودی‌های ولت** روی بلاک‌چین، و دکمه‌های ✅ تأیید و ❌ رد.

### تأیید تمام‌خودکار روی بلاک‌چین (نسخه ۱.۳)
برای **XLM، XRP، TRX، TON و ALGO** سیستم خودش هر دقیقه (و وقتی کاربر صفحه‌ی پرداخت را باز دارد، هر چند ثانیه) ولتت را روی بلاک‌چین نگاه می‌کند. واریزی را که **دقیقاً با مبلغ یکتای سفارش** (و Memo) یکی است پیدا می‌کند و اشتراک را خودکار فعال می‌کند. برایت هم در تلگرام پیام «⚡ تأیید خودکار» می‌آید.
- `/set coin_auto auto` — خودکار فعال کند (پیش‌فرض)
- `/set coin_auto detect` — فقط پیدا کند و تو با یک لمس تأیید کنی
- `/set coin_auto off` — همه دستی
- **امنیت:** فقط خود ارز اصلی شبکه حساب می‌شود (توکن‌های تقلبی با همان عدد رد می‌شوند). در XRP مبلغ «واقعاً رسیده» ملاک است، نه مبلغ ادعاشده. فقط تراکنش‌های تأییدشده قبول می‌شوند. هر تراکنش فقط یک سفارش را پرداخت می‌کند. اگر مبلغ کمی **کمتر** رسیده باشد (مثلاً صرافی کارمزد کم کرده)، خودکار فعال نمی‌شود و برای تصمیم تو در تلگرام می‌آید.
- بقیه‌ی ارزها (SOL، LTC، DOGE، BCH، BNB، POL) مثل قبل با یک لمس تو تأیید می‌شوند.

## نسخه ۱.۴ — درگاه کارت‌به‌کارت در حد درگاه بانکی
- **مبلغ یکتا:** هر سفارش چند تومان اضافه دارد (مثلاً ۱۸۹٬۰۳۸) تا هر واریز دقیقاً به یک سفارش وصل شود. سه رقم آخر در اپ طلایی نشان داده می‌شود و معادل **ریالی** هم با دکمه‌ی کپی هست (`/set card_unique 0` برای خاموش کردن).
- **کارت بانکی زیبا** با رنگ بانک؛ بانک از شش رقم اول کارت تشخیص داده می‌شود. شماره کارت اشتباه (الگوریتم Luhn) را ربات قبول نمی‌کند.
- **تأیید خودکار با پیامک بانک:** دستور `/sms` در ربات آدرس و مراحل را می‌دهد. روی گوشی‌ای که پیامک بانک می‌آید، اپ رایگان و متن‌باز **Incoming SMS to URL forwarder** (F-Droid یا Releases گیت‌هاب) را نصب کن و آن آدرس را در آن بگذار.
  - **ضد پیامک جعلی:** فقط پیامک فرستنده‌هایی که خودت با دکمه‌ی «🏦 این فرستنده بانک من است» تأیید کرده‌ای، سفارش را خودکار فعال می‌کنند. پیامک از شماره‌ی ناشناس، حتی با مبلغ درست، فقط برای تأیید تو می‌آید.
  - پیامک تکراری، پیامک برداشت/خرید، و خط «مانده» نادیده گرفته می‌شوند. اگر دو سفارش با یک مبلغ باز باشند، تصمیم با تو است.
  - **بدون نصب اپ:** پیامک واریز را کپی کن و برای ربات بفرست؛ سفارش پیدا و فعال می‌شود.
  - `/set card_auto auto|detect|off` (پیش‌فرض auto).

## نسخه ۱.۵ — مهندسی اتصال
- **هوش اپراتور:** Cloudflare اپراتور هر کاربر را رایگان تشخیص می‌دهد (همراه اول، ایرانسل، مخابرات، شاتل و ...). اپ نتیجه‌ی تست و اتصال هر سرور را **ناشناس** (بدون شناسه‌ی کاربر) گزارش می‌دهد و هر کاربر سروری را می‌گیرد که روی **اپراتور خودش** بهتر کار کرده. اگر داده کافی باشد، اتصال هوشمند **بدون تست، در حد ۲ ثانیه** وصل می‌شود. در لیست سرورها نشان «★ بهترین روی همراه اول» دیده می‌شود. داده‌ها بعد از ۱۴ روز پاک می‌شوند.
- **امتیاز کیفیت زنده:** از پینگ، لرزش (Jitter) و افت بسته در یک دقیقه‌ی اخیر: «کیفیت ۹۲ · عالی».
- **خودترمیمی:** اگر همه‌ی سرورهای امتحان‌شده جواب ندادند، اپ لیست سرورها را از پنل تازه می‌کند و دوباره تلاش می‌کند.
- **Kill Switch:** راهنمای یک‌لمسی برای روشن کردن «VPN همیشه روشن» و «مسدود کردن اتصال‌های بدون VPN» در خود اندروید.

## نسخه ۱.۶ — هوش استانی و سرورهای سالم برای گوگل/Gemini
- **هوش شهر و استان:** کیفیت هر سرور جدا برای «اپراتور + استان» حساب می‌شود و ساعت‌های اخیر وزن بیشتری دارند (نیمه‌عمر ۱۲ ساعت). اگر امروز در مشهد سروری بسته شد، همان‌جا در چند ساعت کنار می‌رود و به تهران آسیبی نمی‌زند. استانی که هنوز داده‌ی کافی ندارد، از تصویر کل کشورِ همان اپراتور استفاده می‌کند.
- **تست گوگل و Gemini روی هر سرور:** بعد از اتصال، اپ از **داخل همان کانفیگ** بررسی می‌کند گوگل این IP را کجا می‌بیند (همان روش اسکریپت متن‌باز RegionRestrictionCheck): کشور از دید گوگل، باز بودن Gemini، و کپچای «unusual traffic». نتیجه ناشناس جمع می‌شود و روی هر سرور برچسب می‌آید: «Gemini ✓»، «گوگل: ایران» یا «کپچای گوگل».
- **انتخاب کاربر:** فیلتر «مناسب Gemini و گوگل» در لیست سرورها، **حالت گوگل** در تنظیمات اتصال (اتصال هوشمند فقط سرورهای سالم را انتخاب می‌کند)، و دکمه‌ی «تست گوگل و Gemini روی همین اتصال».
- **ضد نشت:** DNS و WebRTC از داخل تونل می‌روند، IPv6 بیرون تونل از طرف خود اندروید مسدود است (نشت IPv6 ندارد) و QUIC بسته است.
- **برای مدیر:** `/google` نشان می‌دهد کدام سرورها را گوگل «ایران» یا مشکوک می‌بیند تا خروجی آن نود را عوض کنی (مثلاً WARP یا یک IP تمیز).

## نسخه ۱.۷ — طراحی مشکی و طلایی «هاله‌ی آرام»
- **هویت تازه:** کل اپ مشکی و طلایی شد. زمینه مشکیِ گرم و متن‌ها عاجی است. طلا فقط روی دکمه‌ی اصلی هر صفحه، حالت فعال و نشان برند می‌آید تا جلوه‌ی لوکس داشته باشد و شلوغ نشود.
- **دکمه‌ی اتصال «هاله‌ی آرام»:** یک دیسک مشکی صیقلی با حلقه‌ی باریک طلایی. این طرح را از بین چهار طرح انتخاب کردی.
  - قطع: کم‌نور.
  - در حال اتصال: نقطه‌ای نور دور حلقه می‌چرخد.
  - متصل: حلقه کامل و درخشان می‌شود، یک موج نور یک‌بار پخش می‌شود و پشت دکمه نور گرم می‌گیرد.
  - همین نشان در صفحه‌ی شروع، صفحه‌ی خرید (کسوف طلایی)، صفحه‌ی موفقیت (با تیک)، منو، کارت اشتراک و **آیکن اپ** هم هست.
- **تایپوگرافی:** عنوان‌ها، تایمر و قیمت‌ها با فونت نسخ **Markazi Text** (مجوز آزاد OFL)، متن‌ها با وزیرمتن.
- **تصاویر:** تصاویر معرفی اپ و صفحه‌ی دعوت طلایی شدند و کره‌ی زمین صفحه‌ی اصلی هم طلایی شد.
- **ریزه‌کاری‌ها:**
  - کارت اشتراک شبیه کارت عضویت VIP شد.
  - QR پرداخت ارزی طلایی روی مشکی است.
  - صفحه‌ی خالی «پرداخت‌های من» دکمه‌ی «دیدن پلن‌ها» دارد.
  - هنگام اتصال، متن وضعیت درست نشان داده می‌شود.
  - روی گوشی‌های کوتاه، دکمه‌ی اتصال کمی کوچک می‌شود تا با تایمر و کره هم‌پوشانی نداشته باشد.

## نکته‌های مهم
- **دسترسی از ایران:** مشتری قبل از خرید فیلترشکن ندارد، پس سرور باید بدون فیلترشکن باز شود. Cloudflare معمولاً در ایران در دسترس است، مخصوصاً با دامنه‌ی خودت. اپ چند آدرس را امتحان می‌کند (`CG_API_BASE` با کاما) و اگر کاربر VPN وصل داشته باشد از همان مسیر هم تلاش می‌کند. اگر خواستی مطمئن‌تر شود، می‌توانیم بعداً یک «تونل راه‌انداز» (کانفیگ مخفی داخل اپ فقط برای ارتباط خود اپ) اضافه کنیم؛ آن بخش باید روی گوشی واقعی تست شود.
- **امنیت رمزها:** رمز کاربرها با یک «فلفل» مخفی (SECRET_KEY) ترکیب و بعد هش می‌شود. حتی اگر یک نفر به دیتابیس برسد، بدون SECRET_KEY نمی‌تواند رمزها را باز کند. پس `SECRET_KEY` را عوض نکن و جایی لو نده.
- **بازیابی رمز:** چون ایمیل تأیید نداریم، اگر مشتری رمزش را فراموش کرد، در ربات `/reset ایمیل رمزجدید` بزن.
- **پشتیبان‌گیری:** داده‌ها در دیتابیس D1 کلودفلر است. برای گرفتن پشتیبان: در Cloudflare → Workers & Pages → D1 → cloudgold → Export، یا با دستور `wrangler d1 export`.
- **محدودیت‌های رایگان Cloudflare:** ۱۰۰٬۰۰۰ درخواست در روز و ۵ گیگ دیتابیس — برای چند هزار مشتری کافی است.
- **پرچم کشورها:** اگر اسم سرورها در پنل با ایموجی پرچم شروع شود (`🇳🇱 Netherlands`)، اپ کشور را روی کره نشان می‌دهد.
- **مجوز v2rayNG (GPL-3.0):** اگر اپ را پخش می‌کنی، باید سورس پوشه‌ی `android` را هم در دسترس بگذاری.
- **دیدن فروشگاه روی کامپیوتر (اختیاری):** در پوشه‌ی `worker` دستور `node --experimental-sqlite test/dev_server.mjs` را بزن و `http://127.0.0.1:8787/` را باز کن. تست‌های خودکار سرور: در همان پوشه `node --experimental-sqlite test/run.mjs`.

راه‌اندازی این نسخه چند قدم دارد. از قدم ۱ شروع کن و هر جا گیر کردی یا خطا دیدی، عکس صفحه یا متن خطا را بفرست تا با هم حلش کنیم.
